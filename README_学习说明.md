# 学习说明

本文件是学习使用说明。课程原始文件存放在官网及另行保存的离线资料中，不随本 GitHub 进度同步仓库一起保存。

## 推荐的学习节奏

每次围绕一个知识点完成一个小循环，不以下载数量或视频观看时长代替学习效果：

1. **确认范围**：阅读课程日历或本节提纲，确认本次要解决的问题。
2. **学习概念**：阅读讲义，按需要结合视频；写下定义、适用条件与一个例子。
3. **独立练习**：先尝试作业或课堂题，卡住时记录具体卡在哪一步。
4. **核对与订正**：做过以后再看答案，区分概念错误、方法选择错误和计算错误。
5. **留下下一步**：记下待复习点与下一次起点，不把“看过”直接记为“掌握”。

使用 AI 辅助时，建议先让它解释题意或给出一条提示，再逐步展开；题号、教材版次、原题条件和答案仍应对照原始材料核验。

Strang 的开放教材 *Calculus* 可作为微积分补充读物，不能当成以上教材的同一本书。商业配套教材全文不在本资料整理范围内。

## 概率与统计资料怎么用

18.05 可按“课前阅读 → 课堂问题 → 作业 → R 实践 → 阶段考试”的顺序使用。已有其他概率论教材主线时，建议按知识点补充，不把不同课程的课次或进度混在一起。

课程的在线答题检查器与部分 Mathlets 演示需要联网。保存课程提供的 R 代码不等于已经安装 R 或 RStudio，运行前需自行准备环境。

## 已获取离线资料时

以下路径只适用于另行获取的完整本地资料，不是本 GitHub 进度同步仓库中的文件链接：

- 打开根目录的 `START_HERE.html`，或对应课程目录里的 `index.html`。
- `static_resources/` 存放实际 PDF、代码和数据等；`resources/` 主要为资源介绍网页。
- 如果资源介绍页的相对链接打不开，可到 `static_resources/` 按文件名查找。
- 下载清单中的 SHA-256 用于核对具体文件是否与记录一致；不能据此认定每页内容、每个网页链接或所有交互功能都已验证。
- 保留原始课程资料及版权声明，把自己的笔记放在独立文件中。
